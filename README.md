**E-Commerce Business Analytics** This internship project focuses on analyzing e-commerce business data and transforming raw datasets into meaningful business insights using data analytics and Power BI visualizations.
The project was completed over four weeks and covers data preparation, exploratory data analysis (EDA), interactive dashboard development, and business recommendations.

🎯 Project Objectives

- Analyze sales performance and business trends.
- Understand customer purchasing behavior.
- Evaluate delivery operations.
- Identify top-performing states and product categories.
- Analyze customer reviews and satisfaction.
- Study payment behavior.
- Generate actionable business recommendations.

🛠️ Tools Used

- Power BI
- SQL
- Excel
- Google Docs

📅 Internship Timeline

### Week 1: Project Understanding & Data Preparation

- Understood the e-commerce dataset
- Defined project objectives
- Explored different data tables
- Prepared the data for analysis

### Week 2: Data Cleaning & Exploratory Data Analysis (EDA)

- Handled missing values
- Removed duplicate records
- Performed Exploratory Data Analysis (EDA)
- Identified sales, customer, and payment trends

### Week 3: Power BI Dashboard Development

- Built interactive Power BI dashboards
- Designed 7 analytical pages

### Week 4: Final Business Pack & AI Insights

- Generated business insights
- Created business recommendations
- Prepared final report and presentation
- Documented project files
